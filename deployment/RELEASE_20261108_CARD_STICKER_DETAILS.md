# انتشار دکمهٔ مشخصات استیکر کارت — ۸ نوامبر ۲۰۲۶

دکمهٔ «🎴 مشخصات نام کارت · فرم» به استیکرهای تازهٔ کارت در دریافت اولیه، Claim، ارتقا، مجموعهٔ خصوصی، پیش‌نمایش خصوصی Quick و ارسال مستقیم کارت انتخابی/برندهٔ Deck اضافه و روی VPS منتشر شد. [راهنمای رفتار و محدودیت‌ها](../docs/CARD_STICKER_DETAILS_FA.md).

لمس دکمه، نام و فرم صریح همان پیام و چهار عدد پایهٔ فعلی کارت را در پنجرهٔ کوچک تلگرام نشان می‌دهد؛ استیکر، منوی مسابقه و موجودی تغییر نمی‌کنند. پنجره، گزارش تاریخی نبرد یا اعداد پس از اثر زمین/ابیلیتی نیست. callback پس از restart هم کار می‌کند و نام/داده با محدودیت طول تلگرام سازگارند.

کارت رسمی در گروه قابل بررسی است؛ مشخصات کارت سفارشی فقط در پیوی صاحب grant فعال نمایش داده می‌شود و در هر کلیک دوباره کنترل می‌شود. اعداد مخفی Easy و انتخاب‌های نبرد نمایش داده نمی‌شوند. دکمه‌های تأیید inline، آواتار و snapshot رسانهٔ NPC حفظ شده‌اند.

## بررسی

- اجرای کامل Python 3.12 محلی روی SQLite موقت: **1226 passed / 2 skipped / صفر failure و error**. پوشهٔ TMPDIR مطابق guard آفلاین داخل ریشهٔ تست قرار گرفت.
- دو Skip محلی، تست Telegram زنده و تست قفل Linux flock روی Windows هستند؛ تست flock در CI لینوکسی هر دو نسخه اجرا و موفق شد.
- ۲۴۳ تست مرتبط آفلاین با Python 3.12 موفق شدند (۱۲۴٫۶۴ ثانیه). تست‌های جدید، callback واقعی Telegram، چهار ویژگی عمومی، فرم صریح، حد UTF-16 و callback، کلیک تکراری بدون تغییر SQLite، دسترسی/لغو دسترسی سفارشی و اتصال دکمه به استیکر کش‌شده و fallback را پوشش می‌دهند.
- انتظار تست‌های قدیمی دریافت کارت، مجموعه، Quick و شبیه‌ساز بستهٔ اولیه با اضافه‌شدن reply_markup هماهنگ شد؛ بررسی فرم واقعی و جلوگیری از ارسال تکراری حفظ شد. ۴۰ تست تکمیلی شامل مسیر onboarding و کنترل مهاجرت در پوشهٔ موقت درست هم موفق بودند.
- CI موفق main: [run 42487925045](https://github.com/kasra-dastranj/telegram-card-game-bot/actions/runs/42487925045). JUnit: test-results-3.11-1: 1227 passed / 1 skipped، test-results-3.9.25-1: 1227 passed / 1 skipped. frontend/JavaScript، بسته‌بندی و CI gate موفق‌اند.
- hash همهٔ 168 فایل runtime و تطابق 164 فایل source با blob canonical همان commit بررسی شد. بسته جداگانه استخراج و Python آن compile شد.
- Graphify با AST-only به ۴۵۱۷ گره، ۱۲۷۰۰ رابطه و ۲۶۸ community به‌روز شد.

اجرای اولیهٔ CI [42479808449](https://github.com/kasra-dastranj/telegram-card-game-bot/actions/runs/42479808449) به سقف زمان رسید: شبیه‌ساز قدیمی send_sticker پارامتر دکمه را قبول نمی‌کرد و تست هم‌زمانی منتظر رخداد ارسال می‌ماند. mockها برای reply_markup اصلاح و انتظار رخداد به ۵ ثانیه محدود شد؛ شرط جلوگیری از اعطای دوباره و یک توالی ارسال حفظ شده است. بستهٔ اجرای متوقف‌شده منتشر نشد؛ انتشار فقط از CI نهایی موفق انجام شد.

## مشاهده روی گوشی

دکمه فقط روی ارسال‌های جدید اضافه می‌شود؛ پیام‌های قبلی بازنویسی نشدند. اتصال دکمه به درخواست ارسال استیکر و پاسخ callback با تست آفلاین بررسی شد؛ پیام واقعی برای QA به Telegram ارسال نشد. محل ساعت را کلاینت تلگرام تعیین می‌کند و باید روی گوشی واقعی بررسی شود؛ این انتشار جابه‌جایی قطعی ساعت یا تغییر طراحی تصویر را ادعا نمی‌کند.

commit مستندسازی بعدی runtime را تغییر نمی‌دهد. اطلاعات محرمانه و دادهٔ بازیکن وارد Git نشده‌اند.

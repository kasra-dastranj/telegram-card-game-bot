# بسته متن شخصیت‌های TelBattle — نسخه ۱

**محتوا:** ۶۰ شخصیت، برای هرکدام دقیقاً سه خط بیوگرافی، و ۳۱۴ شعار قابل انتخاب تصادفی.

- `telbattle_lore.json`: فایل اصلی مناسب Codex و اسکریپت‌های import.
- `characters_biographies.csv`: بیوگرافی و مشخصات هر ۶۰ شخصیت.
- `victory_lines.csv`: ۳۱۴ شعار جداگانه با شناسه و نوع متن.
- `TelBattle_Lore_Editor.xlsx`: فایل Excel برای بازبینی و ویرایش.
- `TelBattle_Bios_and_Victory_Lines_FA.md`: نمایش متنی کامل با دسته‌بندی شخصیت‌ها.
- `CODEX_READ_FIRST.md`: شرح وظیفه Codex و الزامات ورود امن.
- `VALIDATION.json`: گزارش بررسی شمارش و ساختار.

## راهنمای مهم

- `original_game_line` یعنی متن جدیدی که برای بازی نوشته شده؛ نقل‌قول واقعی شخصیت نیست.
- `verified_short_quote` یعنی نقل‌قول کوتاهی که برایش لینک منبع عمومی داریم؛ این **به معنی مجوز استفاده تجاری یا استفاده از صدای شخصیت نیست**.
- شناسه‌های `tb_char_01` و `tb_victory_01_01` موقتی هستند؛ Codex باید با داده‌های فعلی پروژه مطابقت بدهد.
- هیچ شعار یا بیوگرافی را قبل از تأیید صاحب بازی به دیتابیس اصلی وارد نکنید.
- فایل شعارها تعداد ثابت ۵ شعار برای هر شخصیت را الزامی نمی‌کند؛ ساختار از افزودن شعارهای نامحدود حمایت می‌کند.
- کومان یک کارت مشترک کوروش و ایمان است؛ لاک‌پشت‌های نینجا نیز یک کارت مشترک در این فهرست هستند.
- اسامی میمی کمترمستند (دکتر استاپ، بیگ مسعود، کامران اتابکی، داوود ززز) پیش از انتشار نیاز به تطبیق با تصاویر و کلیپ‌های مرجع دارند.

# ظاهر قلعه‌ای Mini App

این تغییر، صفحه‌های فعلی Mini App را با زمینهٔ قلعه، قاب‌های طلایی، کارت خودی آبی و کارت حریف نارنجی نمایش می‌دهد. قوانین بازی، اقتصاد، API و منوی ربات تغییر نکرده‌اند. تصاویر مرجع فقط جهت هنری بودند: عدد، جواهر، Battle Pass، گردونه و دک پنج‌کارتی از آن‌ها وارد بازی نشده است.

## فایل‌ها و تعویض تصویر

- پوستهٔ اصلی در `frontend/game/src/citadel.css` است. ترتیب import در `main.ts` چنین است: `styles.css`، سپس `tabletop.css` برای ساختار صفحه‌ها، و در پایان `citadel.css` برای ظاهر جدید.
- پس‌زمینه در `frontend/game/src/assets/citadel-courtyard.webp` است. این تصویر با ابزار تصویرسازی داخلی از توصیف حیاط قلعهٔ گوتیک، پرچم سرمه‌ای و طلایی، نور آبی و آتش نارنجی ساخته شد. متن، دکمه و کارت در خود تصویر نیستند؛ همه در HTML/CSS و دادهٔ واقعی بازی ساخته می‌شوند.
- برای تعویض تصویر، فایل WebP جدید را با همین نام جایگزین کنید و `npm run build` بزنید. ارجاع `?inline` در CSS تصویر را داخل CSS خروجی قرار می‌دهد تا بستهٔ فعلی انتشار به فایل تصویری جداگانه نیاز نداشته باشد. بعد از build نبودن فایل جداگانهٔ `citadel-courtyard` در `dist/assets` را بررسی کنید.
- تصویر اختصاصی زمین که API در `background_url` می‌دهد، روی زمینهٔ عمومی نمایش داده می‌شود. تصاویر کارت و اسکین نیز از دادهٔ واقعی می‌آیند. تصویر خراب، جایگزین سادهٔ کارت را نشان می‌دهد.

## رفتار رابط

- انتخاب کارت Quick، سه‌راندی و تمرین ASO با فهرست قابل اسکرول و دکمهٔ ثبت انجام می‌شود. اسکرول فهرست هنگام polling و رندر دوباره حفظ می‌شود. دک همچنان سه‌کارتی است.
- کارت حریف تا وقتی سرور `opponent_card` یا `ai_card` را ندهد پشت‌ورو می‌ماند. نتیجه فقط پاداش‌های برگشتی API را نمایش می‌دهد. نوار پیشرفت نتیجه پس از تازه‌خواندن پروفایل نمایش داده می‌شود.
- افکت کوتاه قلب، ارتقا، ابیلیتی، پاداش و پیروزی فقط پس از پاسخ موفق عملیات مربوط اجرا می‌شود. پیام‌های موفقیت، خطا و اطلاع‌رسانی رنگ و نقش دسترس‌پذیری جدا دارند. با `prefers-reduced-motion` افکت نمایشی حذف می‌شود.
- انتخاب کشیدنی قدیمی Phaser دیگر مسیر اصلی انتخاب کارت نیست. Phaser همچنان برای منطق نمایشی قدیمی بارگذاری می‌شود، اما صحنهٔ کارت آن زیر رابط جدید نشان داده نمی‌شود.

## بررسی محلی

در `frontend/game`:

```powershell
& 'C:\Program Files\nodejs\npm.cmd' run build
& 'C:\Program Files\nodejs\npm.cmd' run preview -- --host 127.0.0.1
$env:QA_URL = 'http://127.0.0.1:4173/miniapp-assets/'
node scripts/qa-citadel.mjs
node scripts/qa-redesign.mjs
node scripts/qa-three-abilities.mjs
```

`qa-citadel.mjs` با دادهٔ نمایشی و پاسخ‌های موقت، کارت انتهای فهرست، حفظ اسکرول در polling، محرمانگی کارت حریف، نتیجهٔ بدون پاداش ساختگی، خرید قلب و افکت آن را بررسی می‌کند. `qa-drag.mjs` به ورودی کشیدنی قدیمی وابسته است و معیار پذیرش این رابط نیست. تست مرورگر محلی، تأیید نمایش در دستگاه تلگرام یا انتشار تولیدی نیست.

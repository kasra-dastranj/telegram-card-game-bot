# راهنمای پنل مدیریت کارت TelBattle

## اجرا

از ریشه پروژه اجرا کنید:

```powershell
python web/web_api.py
```

سپس `http://127.0.0.1:5000` را باز کنید. لانچر قدیمی زیر نیز به همین نسخه جدید هدایت می‌شود:

```powershell
python web/web_admin_panel_phase2.py
```

پنل به‌صورت پیش‌فرض فقط روی سیستم محلی گوش می‌دهد. برای اجرای کنترل‌شده روی شبکه، متغیرهای `ADMIN_PANEL_HOST` و `ADMIN_PANEL_PORT` را تنظیم کنید.

## امکانات نسخه فعلی

- ساخت، جست‌وجو، فیلتر، ویرایش و حذف کارت
- اطلاعات پایه فاز اول: نام، کمیابی، نوع، چهار Stat، Ability، Effect، بیوگرافی و دیالوگ‌ها
- داده‌های مودهای جدید: Trait، Series، Hidden Stats مود Easy و Passive مود Quick
- تصویر PNG/JPG/WebP، استیکر WebP محلی و `file_id` عکس/استیکر تلگرام
- اعتبارسنجی مقادیر Stat، شرط و اثر Passive و جلوگیری از نام تکراری

برای ویرایش یک کارت، آن را از فهرست انتخاب کنید، تب مربوط را باز کنید و «ذخیره کارت» را بزنید. در نمایش موبایل، پس از انتخاب کارت صفحه به ویرایشگر منتقل می‌شود.

## نکات رسانه

- تصویرهای آپلودشده در `assets/card_images/` ذخیره می‌شوند.
- استیکر WebP با نام خود کارت در `assets/stickers/` ذخیره می‌شود تا ربات آن را پیدا کند.
- اگر بعد از آپلود استیکر نام کارت را تغییر دادید، استیکر را دوباره آپلود کنید.
- وارد کردن `Telegram file_id` اختیاری است، ولی باعث می‌شود ربات رسانه را دوباره آپلود نکند.

## نسخه قدیمی

ابزارهای جانبی قدیمی مانند تنظیم Cooldown فعلاً در `http://127.0.0.1:5000/legacy` باقی مانده‌اند. مسیر اصلی مخصوص مدیریت کارت‌های نسخه فعلی است.

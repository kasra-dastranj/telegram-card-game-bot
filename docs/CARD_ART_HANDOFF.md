# راهنمای تحویل تصاویر فرم‌های کارت

فهرست فرم‌هایی که هنوز تصویر اختصاصی ندارند در [فهرست تصاویر](../content/card_art_backlog_2026-10-01.json) است. هر ردیف `card_id` و `rarity` دقیق دیتابیس VPS را دارد. فایل‌های Normal فعلی عنوان و عدد را در خود تصویر دارند؛ همان فایل را برای Epic یا Legend ثبت نکنید.

برای هر تصویر آماده، فایل PNG/JPG/WebP را در `assets/card_images` بگذارید. نام فایل باید یکتا باشد، مثلاً `john_wick_epic.png`. یک JSON مانند نمونهٔ زیر بسازید؛ `approved: true` یعنی تصویر و فرم را خودتان بازبینی کرده‌اید:

```json
{
  "images": [
    {
      "card_id": "ea60fec4",
      "rarity": "epic",
      "image_path": "assets/card_images/john_wick_epic.png",
      "approved": true
    }
  ]
}
```

سپس `python scripts/import_card_art.py path/to/manifest.json --db game_bot.db` را برای پیش‌نمایش اجرا کنید. وقتی مسیرها و فرم‌ها درست بود، همان فرمان را با `--apply` تکرار کنید. ابزار وجود و سالم‌بودن فایل، مالکیت `card_id`/فرم، استفاده‌نشدن همان فایل برای فرم دیگر و تکراری‌نبودن ردیف‌ها را بررسی می‌کند. برای فرم پایه، مسیر جدول اصلی کارت را هم عوض می‌کند و cache شناسهٔ رسانهٔ تلگرام را پاک می‌کند. اجرای دوبارهٔ همان Manifest تغییر اضافه‌ای نمی‌سازد.

روی VPS، فایل تصویر ابتدا باید در پوشهٔ مشترک `assets/card_images` نسخهٔ فعال حاضر باشد؛ پس از آن Manifest را با Dry Run و سپس Apply روی دیتابیس زنده اجرا کنید. قبل از Apply از دیتابیس پشتیبان سازگار SQLite بگیرید. این راهنما فقط اتصال تصویرهای آماده را انجام می‌دهد؛ تولید یا تأیید هنری تصویر را انجام نمی‌دهد.
